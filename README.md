# Python Task Manager

A desktop application built with Python that allows users to monitor
their computer's system resources and running processes.

## Features

- View CPU usage
- View RAM usage
- View disk usage
- View battery percentage
- View running processes
- Search for processes
- End selected processes

## Technologies Used

- Python
- Tkinter
- psutil

## Purpose

I created this project to learn more about how Python can interact with
computer system resources and running processes.
